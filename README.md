# clinical_relevance_weighted_odds_ratios
Tools for calculating clinical relevance weighted odds ratios for ordinal outcomes. 

The R programs in this directory are used for implementing the proposed clinical relevance weighted odds ratios for characterizing the treatment effect on ordinal outcomes.

Stratified_model_functions_061026.R contain the functions used in the applied data analysis on the COVID-OUT Dataset. 

covid_out_utilities_081326.qmd contain the code to run the applied data analysis of the publicly available COVID-OUT dataset. To request access to the COVID-OUT dataset, see https://covidout.umn.edu/accessing-data

The adjusted_simulation folder contains all of the code to run and analyze the adjusted simulation study on both a seven level and five level ordinal outcome under various treatment effects. 

The unadjusted_simulation folder contains all of the code to run and analyze the unadjusted simulation study on a five level ordinal outcome under various treatment effects.
